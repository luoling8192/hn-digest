# Personal HN reading

## Language

**Reader**: A Telegram account with its own interests, saved articles, and recommendation history.

**Batch**: An ordered reading list of up to five articles. Article numbers refer to that list only.

**Selection**: Articles marked for an action in one batch. Selection alone is not an interest signal.

**Bookmark**: An article saved to read later. Saving is a weaker interest signal than explicit feedback.

**Feedback**: A reader's explicit request for more or fewer similar articles. Repeating the same feedback does not strengthen it.

**Interest**: A broad reader preference, distinct from the concise retrieval tags displayed in the channel.
